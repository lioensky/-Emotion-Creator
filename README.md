# Emotion Creator - 表情包批量切割创建器

这是一个专为 AI 生成的表情包网格（n x n 宫格）设计的批量切割与重命名工具。支持可视化调整分割线，快速为每个切片命名并一键导出。

## 功能特点

- **可视化分割**：支持自定义行数和列数，实时预览分割效果。
- **手动微调**：支持鼠标**直接拖动红色分割线**，完美对齐 AI 生成的不规则网格。
- **快速命名**：右侧面板提供对应每个切片的输入框，支持在导出前预设文件名。
- **状态保留**：调整网格参数或更换图片时，已输入的文件名不会丢失。
- **智能兼容**：自动处理 RGBA 透明通道，支持导出为 JPG, PNG, WebP 等多种格式。
- **批量导出**：一键将所有切片保存到指定目录。

## 安装与运行

1. **克隆仓库**：
   ```bash
   git clone https://github.com/lioensky/-Emotion-Creator.git
   cd -Emotion-Creator
   ```

2. **安装依赖**：
   ```bash
   pip install -r requirements.txt
   ```

3. **启动程序**：
   ```bash
   python main.py
   ```

## 使用指南

1. 点击 **“导入图片”** 选择您的表情包大图。
2. 在右侧设置 **“行数”** 和 **“列数”**。
3. 如果 AI 生成的图片对齐不准，直接在预览图上**拖动红色分割线**进行微调。
4. 在右侧列表中输入每个表情的 **文件名**。
5. 点击 **“一键批量导出”**，选择保存目录即可。
