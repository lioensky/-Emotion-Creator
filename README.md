# Emotion Creator - 表情包批量切割创建器

这是一个专为 AI 生成的表情包网格（n x n 宫格）设计的批量切割与重命名工具。支持可视化调整分割线，快速为每个切片命名并一键导出。

## 功能特点

- **可视化分割**：支持自定义行数和列数，实时预览分割效果。
- **手动微调**：支持鼠标**直接拖动红色分割线**，完美对齐 AI 生成的不规则网格。
- **批量命名**：粘贴用竖线分隔的多行文本，按网格顺序一次填入切片名，也可逐格修改。
- **名称预览**：每格底部实时显示名称，标签只在预览中出现，不会写入导出的图片。
- **AI 提示词**：按当前行列数生成提示词，一键复制后可随宫格图片一起发给 AI。
- **状态保留**：调整网格参数或更换图片时，已输入的文件名不会丢失。
- **智能兼容**：自动处理 RGBA 透明通道，支持导出为 JPG, PNG, WebP 等多种格式。
- **批量导出**：一键将所有切片保存到指定目录。

## 安装与运行

1. **克隆仓库**：
   ```bash
   git clone https://github.com/lioensky/-Emotion-Creator.git
   cd -Emotion-Creator
   ```

2. **安装依赖**：
   ```bash
   pip install -r requirements.txt
   ```

3. **启动程序**：
   ```bash
   python main.py
   ```

## 使用指南

1. 点击 **“导入图片”** 选择您的表情包大图。
2. 在右侧设置 **“行数”** 和 **“列数”**。
3. 如果 AI 生成的图片对齐不准，直接在预览图上**拖动红色分割线**进行微调。
4. 在右侧列表中逐格输入名称，或在 **“批量命名”** 中粘贴文本，再点击 **“解析并填入”**。每行对应图片的一排，每个名字从左到右排列，用竖线分隔。以 3×3 宫格为例：
   ```text
   开心|失望|生气
   哭了|爱你|比心
   喜欢|难受|伤心
   ```
   如需让 AI 起名，先点击 **“复制 AI 提示词”**，将提示词连同图片发给 AI，再粘贴它返回的纯文本。文本必须与当前网格行列数一致，且名称不能为空或重复；有误时不会覆盖已有名称。
5. 在左侧预览中核对每格名称，再点击 **“一键批量导出”** 并选择保存目录。
